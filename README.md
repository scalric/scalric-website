# Scalric corporate website

Scalric’s responsive corporate website, built from the approved PRD structure with React and Vite. The previous recreation has been retired; its copied branding, content, media references and legacy behavior have been removed.

## Run locally

Use Node.js 22 or later. This project is the website only. The API and the database schema live in the sibling project `scalric-website-backend` (see its README to set up Supabase and start it on port 3001).

```bash
npm install
npm run dev
```

Open the Vite address (normally `http://localhost:5173`). Vite proxies `/api` requests to `http://127.0.0.1:3001`, so start the backend in a second terminal.

## Admin site

The admin UI now lives in the separate `scalric-admin` project (`../scalric-website-admin`, dev port 5174). It uses the same backend's `/api/admin/*` routes; see that project's README.

## Project map

```text
index.html             Vite entry
vite.config.js, vercel.json
public/
  assets/              Wordmark, photos, generated art and cards, video posters
  media/               Hero videos
src/
  main.jsx, App.jsx    Entry and route resolver
  components/          Header, mega menu, forms, shared UI, footer
  pages/               Homepage and route-level page templates
  data/                Structured, replaceable content and taxonomy
  lib/                 Router, API client, roles, form validation (validate.js)
  styles/              styles, premium, theme, impact, ngo, cta (loaded in that order from main.jsx)
scripts/               generate-art.mjs, generate-card-art.mjs
docs/
  architecture.md      Route, component and data-flow map
```

`src/lib/validate.js` is a copy of the backend's `src/utils/validators.js` (the backend enforces it); keep the two in step.

## Routes

`/`, `/what-we-do`, `/industries`, `/insights`, `/insights/:slug`, `/impact`, `/company`, `/careers`, `/careers/:role-slug`, and `/contact`.

## Backend and data

Forms post to `POST /api/contact` and `POST /api/impact/applications`, careers roles come from `GET /api/roles`. All of it is served by `scalric-website-backend`, which stores data in Supabase (Data API) and resumes in a Storage bucket.

## Content to confirm before launch

Insight drafts, proposed industry focus areas, open roles, hiring steps, Impact outcomes and company details are clearly presented as previews or pending confirmation. Impact figures are not invented. Replace draft content only with approved copy and sourced metrics. The sitemap uses `https://scalric.com` as a domain placeholder; update it if the final domain differs.

## Illustrations and theme

Site illustrations live in `public/assets/art/` and are generated by `scripts/generate-art.mjs`. Edit the script and re-run `node scripts/generate-art.mjs` to regenerate them. Images are dependency-free SVG in the Scalric palette. To swap in photographic or AI-generated imagery, place a file in `public/assets/` and point the `ArtImage` component in `src/components/Showcase.jsx` at it.

The visual theme (black base, white type, Scalric green accent) is set in `src/styles/theme.css`, which loads after `styles.css` and `premium.css`. Interactive UI components (ticker, tabs, dashboard preview, sparkline, timeline) are in `src/components/Showcase.jsx`.
